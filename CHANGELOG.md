# Changelog

All notable changes to Markdown PDF Studio will be documented here.

## 1.0.0 - 2026-09-01

- Added configurable Markdown-to-PDF CLI conversion.
- Added a local visual editor with live preview and PDF export.
- Added page, margin, typography, spacing, colour, and code controls.
- Added installed-font discovery and embedded font-file importing.
- Added Windows launchers and an optional browser protocol shortcut.
