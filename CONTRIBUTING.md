# Contributing

Contributions and bug reports are welcome.

## Development setup

1. Install Node.js 18 or newer and Chrome or Microsoft Edge.
2. Install pnpm.
3. Run `pnpm install`.
4. Run `pnpm start` and open `http://127.0.0.1:4173`.

Before opening a pull request, run:

```powershell
pnpm check
pnpm demo
```

Keep changes focused, preserve the zero-build frontend, and include a short manual verification note for PDF layout changes.
