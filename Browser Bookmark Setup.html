Firefox treats this protocol as a search when it is typed into the address bar. Use it as a real bookmark link instead.

Start Markdown PDF Studio
  1. In Firefox, press Ctrl+Shift+B to show the Bookmarks Toolbar.
  2. Drag the purple Start Markdown PDF Studio link onto that toolbar.
  3. Click the new bookmark and allow Firefox to open the Windows launcher.
Do not paste mdpdfstudio://start into Firefox's address bar; Firefox will search for it.
